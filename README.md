# AI Paperwork and Forms Guide

A beginner-friendly manual for using AI to handle everyday paperwork — reading forms, filling out applications, benefits documents, leases, and insurance papers — plus what never to share and how to save your copies.

Plain English. Privacy first. No medical advice, no legal advice. No secrets.

## Chapters

1. **Getting started** — Picking an AI tool, starting a chat, basic safety
2. **Reading forms** — Uploading a form, asking AI to explain it in plain language
3. **Filling out applications** — Drafting answers, reviewing before you submit
4. **Benefits documents** — Understanding benefit letters, appeals, and applications
5. **Leases and rental agreements** — Spotting key clauses, questions to ask your landlord
6. **Insurance documents** — Reading policies, claims, and explanation of benefits
7. **What never to share** — Privacy rules: SSN, passwords, medical details, and more
8. **Saving and organizing your copies** — Where to keep files, naming, backups
- **Privacy checklist** — A before-you-upload checklist you can use every time

## How to run it

No installation or account needed.

- **Markdown:** open any file in `docs/` with a text editor or Markdown viewer.
- **HTML site:** open `site/index.html` in your web browser and use the chapter navigation. Every page links to `assets/style.css` and `assets/script.js` with relative paths, so you can copy the folder anywhere or serve it from any static host.

## Privacy promise

AI is helpful, but it is not a safe place for secrets. This guide includes a "what never to share" chapter and a printable privacy checklist. Read Chapter 7 before you upload anything.

**If you wouldn't show it to a stranger, don't paste it into an AI chat.**
